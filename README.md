# TAISI Summer Intensive Capstone Project

During the month of July I was part of AI Safety Summer Intensive hosted by Toronto AI Safety Initative (TAISI).

As a capstone project I re-implemented [LLM Jailbreaks Exploit Attention Sinks](https://openreview.net/pdf?id=07j8djGxAD).

The presentation slides are [here](https://github.com/gabriel-paulos/TAISI-capstone/blob/main/Re-Implementing%20LLM%20Jailbreaks%20Exploit%20Attention%20Sinks.pdf)

The code is [here](https://github.com/gabriel-paulos/TAISI-capstone/blob/main/forpresen.ipynb)

As an extension I am working on using suffix-based gradient attacks on VLMs to manipulate their attentions sinks and attempt to jailbreak them.
